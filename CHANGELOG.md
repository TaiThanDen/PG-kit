# Changelog

## 1.0.0-beta.2

- Restore watermark date and time to the device clock with one tap; the setting persists across restarts.
- Slide horizontally between photos without fading or clearing the current image while the next photo loads.
- Keep the current photo visible if the next photo cannot be loaded; respect disabled system animations.

The beta.1 hardware and orientation validation limits still apply.

## 1.0.0-beta.1

First downloadable community beta of Timecounter.

- Photo/video capture with reference-style time and location watermarks.
- Portrait interface, physical-orientation-aware output and aspect-ratio controls.
- Hardware-limited zoom/focus/exposure and auxiliary wide-camera support.
- Custom watermark clock and the existing template catalogue.
- Local photo/video gallery, sharing, photo zoom and playback controls.
- Custom launcher icon; original Timemark-style watermark graphics and fonts preserved.
- English project documentation, privacy notes, signing instructions and download checksums.

### Known limits

Full four-direction preview/JPEG/video validation is still pending. Some watermark text remains Vietnamese. Hardware support varies. Reference-style verification labels do not provide real verification. See README and THIRD_PARTY_NOTICES for scope and asset-provenance limits.
