## Correction

Previously the 300px source went directly to the saved-photo destination. Now an
Android ImageView first rasterizes it at rounded 100 native dp, preserving its
alpha, padding and baked shadow. That cached bitmap is projected onto the JPEG
using the existing output geometry. No blur, recoloring, guessed font or new
position correction was added. On LG, 100dp rounds to 251px; at a 1536px photo
short side its destination remains 267.73334px square.

Source remains `assets/video/official_vi.png`, SHA-256:
`d192e612622cae176c561673a8e65aa4b7855d5c060d10a2c01db97c09ac8e2d`.

## Verification

constructed native ImageView raster, pixel for pixel, on LG at 1536×2048,
